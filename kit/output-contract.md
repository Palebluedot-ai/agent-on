# 每轮输出契约：状态面板在前

> 职责边界：本页管**一轮 AI 说完话长什么样**——顺序、面板字段、拍板写法、结论分格、撤销两栏、球在谁那。它不管活该怎么干（那是 phase 卡与各环节 harness 的事），也不管谁有权合并（那是 [值守](babysit/README.md) 的事）。
> **单一真相**：派工词、审查词、Explore 词、值守文档、项目宪法骨架一律**引用本页**，不各自抄一份——抄三份必然各自漂移。
> 源流：2026-08-17 用户实测反馈。同时开多个 worktree、多条会话跑调研与实现、另有值守在合 PR，结果回来的长文读不动：术语看不懂（「悬点」「STALE」「reused-valid」）、对错混着写、拍板散在各处、不知道哪棵树能删。

## 一句话

**一轮结束，用户 30 秒内要能回答三个问题：①整体到哪了 ②我要拍哪几个板 ③哪些树能删。**

答不出来就是这轮输出不合格——跟活干得对不对无关。做对了但说不清，用户照样卡住。

## §1 硬顺序（状态在前，发现在后）

固定六段，顺序不许换：

| 段 | 内容 | 给谁看 |
|---|---|---|
| 1 | **状态面板** | 用户扫一眼 |
| 2 | **要你拍的板** | 用户拍板 |
| 3 | **结论三格** | 用户判断哪条成立 |
| 4 | **撤销面** | 用户决定删不删 |
| 5 | **球在谁那**（一行） | 用户知道在等谁 |
| 6 | 过程、分析、证据、代码细节 | 需要深读的人 |

第一屏必须是面板，**不是**「我先读了 X 又跑了 Y」。把第 6 段的内容提到前面 = 违约。

短轮次可以压缩，但**不许整段消失**——用户靠固定位置扫读。没有可删的树就写「撤销面：无变化」一行带过；没有要拍的板就写「本轮无需拍板」。

### 表格是允许的渲染形式，不是第二份模板

段的**顺序与语义**是硬的，**排版**不是。第 2、3 段用表格渲染往往比列表更好扫。允许的映射只有这一张，不许再立第二份交接模板（自举纪律：一个主题一份 canonical）：

| 表头写法 | 映射到本页哪一段 | 硬要求 |
|---|---|---|
| 「需要我拍板的」`序号 / 事项 / 选项+建议 / 你不回我按哪个 / 卡住谁` | §3 要你拍的板 | 五件齐一件不许少，**默认值列不许省** |
| 「你做的事情」`序号 / 完成内容 / 证据指针 / 状态` | §4 结论三格的「已验证」格 | 第三列写**证据指针**（命令名 / 文件:行 / run id），不写「相关位置」——没跑过的不许进这张表 |
| 「交接给值守」`[编号] 事项 + 当前状态 + 需要值守做什么` | 非值守窗口专用，插在 §4 与 §5 之间 | 编号用 §2 的 `<会话名>#<任务 id>`；「需要值守做什么」必须是动词 |

非值守窗口最容易漏的是**撤销面（§5）与球在谁那（§6）**——这两段不在上面三张表里，但一样不许消失。

## §2 状态面板

一行一条轨，四个字段，顺序固定：

```text
轨名 │ 一句话状态 │ 我要不要动 │ 下一动作归谁
```

- **轨名**：人能认出来的名字（功能名 / PR 标题的头几个字），不是 `claude/eloquent-sanderson-4b245b` 这种机器 id。机器 id 需要时放括号里。

  **跨窗口引用编号 = `<会话名>#<任务 id>`**（2026-08-19 实测落定）。不要另发明编号，Claude Code 已经给了两层现成命名空间，拼起来就全局唯一且**天然可寻址**：

  | 半边 | 从哪来 | 怎么定 |
  |---|---|---|
  | `<会话名>` | `~/.claude/sessions/<pid>.json` 的 `name` | `claude --name <lane-id>` 或 `/rename`；不定则从目录名派生，重名自动加变体后缀 |
  | `<任务 id>` | `~/.claude/tasks/<sessionId>/<n>.json` 的 `id` | TodoWrite 写进去的；带 `blocks` / `blockedBy` 依赖图，会话死了文件还在 |

  可寻址的意思是：会话名就是 SendMessage 的收件地址，也是 prompt 里 `@` 点名的 typeahead 键。值守说「@epic-hertz-483308-e7 你的 #3 卡住了」，消息直接送到那个窗口，不需要任何中间层。
  **前置纪律**：编号要能用，功能会话必须把工作拆进 todo——不拆就没有 `#N`，跨窗口只能靠描述指代。派工词末尾必须带这一句。
- **一句话状态**：一句话说完「它现在怎么了」，带上用户拍板要用的数（PR 号 / 还要多久 / 落后多少）。
- **我要不要动**：只有两个值——`要拍板` / `不用管`。
- **下一动作归谁**：具名角色（见 §6），不许写「应该有人去…」。

### 类别一律中文人话

机器类别名**只准放括号里当索引**，或只进 `--json`。给人看的正文用这一列：

| 中文人话（正文用） | 机器索引（括号里） | 什么时候用 |
|---|---|---|
| 可以合了 | `NOW` | 全绿、依赖已落地、证据有效 |
| 等 CI（约 N 分钟） | `PARALLEL` | CI 在跑，没别的事 |
| 等前面那条 #N | `NEXT` | 只差一条依赖 |
| 红了，等作者修 | `FIX` | CI 红或评审打回 |
| main 动了，要重新追平 | `STALE` | 证据被 base 移动打穿 |
| 没变化，本轮没碰它 | `SKIP` | 两个 SHA 都没动 |
| 在做 | `ACTIVE` | lane 活跃，脏是常态 |
| 停着，上下文已存 | `PARKED` | 干净、无孤本的暂停 |
| 等着，不用管 | `WAITING` | 等 CI / 评审 / 依赖 / 静默期 |
| 别删，有孤本 | `RESCUE` | 脏 / 未推 / 有独有提交 |
| 能删 | `REAPABLE` `CANDIDATE` `safe` | 三条证据齐（见 §5） |

新增类别前先问：现有中文人话够不够用？**每加一个词都要付「用户看不懂」的成本。**

### 示例

```text
auth-api    #182 全绿可合，等你一句话        │ 要拍板 │ 值守
ui-shell    #187 CI 在跑，约 8 分钟           │ 不用管 │ 值守
data-model  #186 测试红了                     │ 不用管 │ 作者会话（agent-on-data 轨）
docs-fix    已合并，树干净无孤本              │ 不用管 │ 能删（命令见撤销面）
```

## §3 要你拍的板（收成一节）

编号，每条 **≤3 行**，五件齐：

1. **问题**（一句话，不铺垫）
2. **选项 A / B**
3. **我建议哪个 + 为什么**（一句）
4. **你不回我就按哪个走**（必写，没有默认值的拍板不许提交）
5. **不拍会卡住谁**（具名；不卡任何人就直说「不拍谁都不卡」）

### 默认值默认等于建议值（2026-08-19 用户实测催生）

> 用户原话：「为什么我不回按照不是建议的来，看起来很奇怪。」

**规则**：第 4 条的默认值**默认就写第 3 条的建议值**。只有两种情况允许降级到保守选项，且必须在括号里写明降级理由：

1. **不可逆**——删除、force-push、外向发布、花钱、动别人的东西；
2. **超出已授权范围**——落在[值守授权分级](babysit/MERGE-POLICY.md) §4「必须先问档」，或本会话没拿到过的口头授权。

**为什么这条是硬的**：如果建议与默认系统性地不一致，用户就学会了「沉默 = 拿到较差结果」，于是被迫每条都回——这正好抵消了拍板前移的全部收益。保守是有代价的，代价要付在真正不可逆的地方，不许到处付。

自查一句：**这条动作可逆吗？在授权内吗？两个都是「是」，默认就必须等于建议。**

### 一轮最多 3 条

超过 3 条时，**自己排序，只问最阻塞的**，其余写默认值先走，把它们降级进 §4 的假设格。不要把裁决成本整体转给用户。

判断「阻塞」的顺序：会造成不可逆动作 > 会让本轮产出作废 > 只是少个数字。

### 写法示例

> **1. 先合 PR #4 吗？**
> 本仓硬门要求交付轮次必须封 CHANGELOG，但 CHANGELOG 被 #4 占着。A：先合 #4，一轮改到位。B：本轮绕开，列接线单等 #4 落地再补。
> **我建议 A**——#4 纯文档、全绿、无冲突。**你不回我就按 B 走**（不阻塞，代价是多一次接线）。不拍卡住的是本轮收尾，不卡内容产出。

## §4 结论三格

同一轮里的自我反复**不进正文**。只留最终结论，外加一行「此前 X 的说法已作废」。

| 格 | 写什么 | 硬要求 |
|---|---|---|
| **已验证** | 跑过命令、看过输出的事实 | 每条附证据指针（命令名 / 文件:行 / run id）；没跑过就不许进这格 |
| **未验证的假设** | 「我按这个假设做了，你不否就当成立」 | 每条必写**否掉要重做什么** |
| **已推翻** | 本轮或此前说过、现已确认不成立的 | 一行说清，不复述推理过程 |

### 不叫「悬点」

「悬点」是给机器看的词，用户看不出要自己干什么。统一写成**「我按这个假设做了，你不否就当成立」**，后面跟一句「否掉要重做：……」。

派工词、审查词里原来写「契约悬点栏」的地方，一律改成这句。机制不变（假设必须显式交出来），只换成用户读得懂的说法。

## §5 撤销面（固定两栏）

### 可以删

三条证据**必须全中**，缺一条就进「不能删」：

1. **已合流有权威证据** —— PR 状态是权威（`gh pr view`）；`merge-base --is-ancestor` 的「是」可作正证据，「否」在 squash 场景不能证明未合
2. **无孤本** —— 没有未推送、也没有未被目标 base 或 MERGED PR 覆盖的提交
3. **工作区干净**

齐了就**附一条待用户执行的命令**，不代删：

```bash
git worktree remove <绝对路径>
```

### 不能删

每条写**原因 + 抢救的下一动作 + 归谁**。

**`unknown` 一律进这栏**——查不到 PR 状态、没有 upstream、审计跑不完、归属不明，全按「不能删」处理。不许因为「看起来是干净的」就放进可删栏。

## §6 球在谁那（最后一行）

一行，四选一，必须具名：

- 等你拍板（第 N 条）
- 等 CI（约 N 分钟）
- 等 `<具名会话>` 修
- 在跑（预计 N 分钟）

## §7 多个结果同时回来

**禁止把 N 份平行报告直接倒给用户。** 先收口成**一份**合并面板：

- 一行一条轨，用同一套字段（§2）
- 谁在合、队列顺序、谁排在谁后面，写在面板里
- 各份报告的细节进第 6 段，或收进指针（「细节见 X」），不进第一屏

子代理回报同样受本契约约束——把本页当派工词的附件发下去，不要让每个子代理自创格式。

## §8 具名角色（禁止无主语）

| 角色 | 干什么 | 面板里怎么写 |
|---|---|---|
| **值守** | 合并权唯一：追平、分诊、请拍板、merge、记账、回执 | `值守` |
| **作者会话** | 修自己那条轨的红、解自己的冲突 | `作者会话（<lane id>）` |
| **控制轨** | 排队、裁决依赖、开轨收轨、合流后记账 | `控制轨` |
| **用户** | 只拍板与授权 | `你` |

「应该有人去改一下」「建议后续处理」这类没有主语的句子 = 违约。**每个动作都要指到上面四个之一。**

值守把真缺陷打回作者时，必须同时告诉用户一句「**这单已不占你注意力**」——用户要知道自己可以把它从脑子里划掉。

## §10 搬到别的项目（自包含，不依赖本仓其它文件）

本页**照抄即用**，不需要先读 kit 里任何别的东西。项目接入三步：

1. **拷贝**：把本页拷到项目仓 `docs/output-contract.md`（或直接在项目 AGENTS 里引用 agent-on 的这份，二选一，别两份都有）。
2. **在项目宪法里点名**：项目 `AGENTS.md`（或等价物）加一句，**位置越靠前越好**：

   > **报告即数据**：所有会话与子代理的每轮输出统一走 `docs/output-contract.md`——状态面板在前 → 拍板收成一节带默认值 → 结论三格 → 撤销两栏 → 球在谁那 → 之后才是过程。类别一律中文人话，机器类别名只准放括号里。

3. **在派工词末尾挂一句**（给子代理的 prompt 都加）：

   > 完成报告格式照 `docs/output-contract.md`；你没验证过的假设写成「我按这个假设做了，你不否就当成立」，每条注明否掉要重做什么。

装了值守的项目再加一步：授权分级与时延目标照 [babysit/MERGE-POLICY.md](babysit/MERGE-POLICY.md) 抄一次，X 要算成具体数字写死。

**没装 agent-on CLI 的项目照样能用**——本页只约束「话怎么说」，不依赖任何命令。面板里的事实从 `git worktree list` / `gh pr list` / `gh pr checks` 就能拿全，机器类别对照表（§2）用不上的行直接删。
