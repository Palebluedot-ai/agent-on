## §1 铁律(三条,轻装也不许省)

1. **完成 = 贴命令实际输出**:任何「完成」声明附验证证据,禁止「应该没问题」。
2. **暂停项写成禁令**:[用户说「以后再说」的,逐条列在这];未写明允许即禁止。
3. **外向硬门先确认(push 与开 PR 不在内)**:提交 / 推**自己的**分支 / 开 PR = 本轨内部动作,自己做不问(本地独有提交久留不推**才是**事故)。须点头的是:merge · tag · release · 直推受保护分支 · force-push · 删远端分支 · 对外发言(PR 评论/邮件/IM/webhook)· 部署 · 建远程资源 · 改共享配置 · 花钱。**授权幂等**:同类动作一次点头长期有效,不逐次追问;跨到没点过头的新类别才重新问。**假定一切 CLI 在非交互环境自动 yes**(喂 n 不是护栏)。
