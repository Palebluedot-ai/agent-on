### subagents-inherit-session-worktree-isolation（从隔离会话派出的子代理，钉在派出者的树上，写不进别的 worktree）

- source：Dartify @ `feebcacf` | pin v0.19.0 (8bd88aa)
- evidence：2026-09-24 SV2 三路并行（#265 SV2-B 10:53、#266 SV2-A2 11:04、#267 SV2-A3 11:26 合入）。一开始是先手工 `git worktree add` 三棵树、装好依赖，再用 Agent 工具派三个子代理各进一棵，结果三个全撞墙：Write/Edit 被拒（宿主原文「Edit the worktree copy of this file instead of the shared-checkout path」）；`cd <别的树> && git …` 被拒（「a worktree-isolated session's git operations must target its own worktree」）；`EnterWorktree(path=…)` 报成功，之后连 `pwd` 都被拒；非 git 命令（cp / flutter pub get）倒能过。三路并行最后变成三份躺在 scratchpad 里的草稿。改用 Agent 的 `isolation: "worktree"` 之后，同一天三条收尾代理加两条复核代理都跑通了 git / flutter / gh pr create，树落在 `.claude/worktrees/agent-<id>`，从 origin/main 起。（宿主拒绝文案引自当日会话记录。）
