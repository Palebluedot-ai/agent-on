# 2026-08-20 · 边界闸分层：互斥闸只在「真有人在写」的轨之间成立

> 职责边界：本快照记录一次方向性决策——互斥 owns 闸的判据从「有没有未落地的改动」改成「有没有人在写」，以及配套的事实收窄与债务口径。机制正文在 [kit/worktree-control-plane.md](../kit/worktree-control-plane.md)「谁还持有边界」一节；本文件只留为什么链。

## 一句话

**恒红的闸等于没有闸。** v0.12.1 的互斥闸对任何持有未落地改动的轨都保留全部纸面 `owns`，而一棵被遗弃的脏 worktree 永远持有未落地改动——于是「防止漏报」的机制变成了「保证恒报」，且只会随废弃树的数量单向恶化。

## 病灶：一条判据同时回答了两个问题

`owns-gate-by-facts`（PR #23，已 landed）给闸补了一个正确的事实维度：登记成 `landed` 但实际在写的轨，不能因为忘了改 `status` 就关掉闸。判据落在 `holds_unmerged_work`——**工作区脏，或有 base 没收进去的 commit**。

意图对，但那条判据同时是**另一个问题**的答案：

| 问题 | 归谁管 | 那条判据的表现 |
|---|---|---|
| 有人正在写这里吗？ | 互斥闸 | 会误答「是」——废弃树永远脏 |
| 有东西没救走吗？ | `gc` 的 `rescue` 分类 | 答得完全正确 |

`rescue` 库存**天然长期存在、天然互相重叠**（同一份脏状态被复制在几棵废弃树里，两两全撞）。拿它驱动互斥闸的输出，闸必然恒红。这是结构性的，不是配置没调好。

还有第二层放大器：非 live 轨进闸时**带着全部纸面 `owns`**。上一版把「事实」加在了「要不要参与检测」那一侧，**没加在「参与时带哪些边界」那一侧**——半程。一条声称 3 个路径、实际只改了 1 个文件的过期轨，照样锁着另外 2 个。

## 决策：三档持有，按事实判

1. **契约档**（`active`/`blocked`/`ready`）→ 持有 `owns` 全量。活轨会回来，有权预留还没写的地盘。**这一档不设时效**——`active` 的意思就是有人说了「我还回来」；要释放文件域用 `parked`，不用等它自己过期。
2. **在写档**（登记完结但仍有未落地改动，且窗口内被碰过）→ **只持有它实际有改动的那些路径**。过期的登记预留不了任何东西。
3. **休眠档**（同上但超过窗口没人碰）→ **不持有边界**，改走 `RESCUE-DEBT` 行；回收分类仍是 `rescue`，仍然不许删。

休眠的判据是**工作本身的年龄**：未落地改动所涉文件的最新 mtime，与 base 没收进去的最新 commit 时间，取大者。选它而不选目录 mtime 或 git index mtime，是因为后两者会被只读盘点自己刷新——闸不能被自己的观测行为改变。

窗口默认 7 天，`agent-on/config.json` 的 `dormant_after_days` 可配，**`0` 关掉休眠**——配错只会让闸更紧。工作区脏但 git 描述不了的树按「在写」处理，fail-closed。

## 为什么这不是把闸放松了

三条都保住了：

- 两条真的在写同一路径的轨 → 照红（`two_live_writers_on_one_path_still_fail`）；
- 登记成 `landed` 但正在写的轨，对它**真的在改**的路径 → 照拦（`writing_landed_lane_still_holds_the_path_it_changed`，及 PR #23 留下的 8 条回归）；
- 活轨的契约不过期（`active_lane_never_goes_dormant`）。

被摘掉的只有一类：**纸面上声称、事实上没人在写**。那一类从来不是冲突，它是抢救债——现在有了自己的口径和自己的出口。

## 顺带的一条元教训

「越保守越安全」在**有收敛压力**的系统里成立，在没有的系统里不成立。红灯要么能被清掉，要么会被无视——没有第三种结局。所以这次的分档规则是：**清得掉的挂红灯，清不掉的挂债**。`RESCUE-DEBT` 改登记清不掉，只有真把改动救走才会消失，所以它不上红灯；边界重叠改一次 `owns` 就能清，所以它上。

## 未做（本轨显式不做）

- **共享文件写权租约**：`docs/requirements.md`、`progress.yaml`、`dashboard.html`、`CHANGELOG.md` 这类顺序资源注定被多轨想写，现在靠「谁 claim 到算谁的」。实测见过写权转移只写在 lane 的 `goal` 散文里（「写权交回 X 轨」），机器读不到。该在 lock/config 声明 `shared_paths` + 带过期时间的租约，另开一轨。
- **claim 入口卫生**：拒父子冗余（同时声称 `docs/**` 与 `docs/requirements.md`）、拒把资产目录逐文件列进 `owns`、`owns` 超阈值要显式确认。见过 89 条 `owns` 的占位轨——那不是边界，是 `git status` 的复印件。入口挡比出口报错便宜一个量级。
