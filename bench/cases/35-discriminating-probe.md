# 案例 35:判别式探针 vs 压力测试

> 层级:L2 | 来源:Dartify 2026-08-15 | 入册:2026-08-16

## 症状
验上游是否真支持严格 `json_schema`:对照松 JSON 会编白名单外的值;上 strict 后回白名单内;再明令输出枚举外仍合规——看起来 enum 生效,但排除不掉「模型自己想通了」。

## 修法
在 schema 里加提示词从未提及的暗号字段 `schema_marker: enum["ZQX-7788"]`,模型原样吐出才判定 schema 在驱动采样。另递一个非法 schema(integer + 字符串 enum),上游 200 不报错 → 下游事后校验一条都不能撤。

## 可复用规则
证明约束生效,要「只有约束成立才可能出现」的值,不要只靠压力测试。约束本身写错会不会有人告诉你,是第二问。
