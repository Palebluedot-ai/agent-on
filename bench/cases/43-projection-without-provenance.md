# 案例 43：没有回指的投影（判定错与幽灵 lane 是同一个病）

> 层级：L1 结构性 | 来源：agent-on 自举实测 2026-08-20 | 入册：2026-08-20
> 职责边界：本页记这一类翻车的形状与识别器。制度正文在 [playbook/truth-hierarchy.md](../../playbook/truth-hierarchy.md)「仓内投影」一节，为什么链在 [snapshot/2026-08-20-projection-drift.md](../../snapshot/2026-08-20-projection-drift.md)。

## 症状

同一天，两件看起来无关的事：

1. 一条关于机器行为的断言（「guard 只拦 push 不拦 commit」）被会话判定为缺陷，值守独立读源码复核后推翻——`commit` 与 `push` 一起进 `commit_push_dirs`（<!-- src: cli/src/guard.rs#commit_push_dirs -->）。
2. 五条 lane 指着已经不存在的 worktree 挂在台账上，谁都没发现，也没有任何命令会报它们。

用户的判断是这两件事同源，而且是通篇的结构问题：**低内聚、高耦合**。

## 根因

仓里每一条持久记录都是两类之一，而这个仓从来没把它们分开：

- **原件**：这里第一次产生的判断。**不会过期**——当时的判断永远是当时的判断。
- **投影**：别处事实的副本。**会过期，而且没有声音**，因为副本不知道自己是副本。

三段式，**不需要任何一份文件写错**就能产出错误结论：

1. **一个机器事实有 N 份投影**。实测（仅 md，排除 `.git`/`target`/`legacy`/`intake`，共 139 份）：`landed` 出现在 **70** 份、`owns` 47 份、`PreToolUse` 32 份，而定义它们的地方各只有一处代码。
2. **投影不带回指，或只回指到文件**。本仓其实已经自发形成了「机制正文在 X」的习惯，但它写在散文里、指到**文件**、没有任何东西验它——而**文件路径不会因为里面的行为变了就失效**。实测：出事的那份快照确实点名了 guard 的实现文件，指针至今有效，基于它的行为断言却是错的。
3. **读者落在任意一份投影上，把它当事实**。原件与投影写在同一份文件、同一种语气、同一个时态，读者没有任何线索去区分「这句要复核」和「这句不用」。

放大器有两个：

- `AGENTS.md` 文档纪律第 3 条「可以重复关键事实，不为了去重而交叉引用」——**对原件成立，对投影致命**。重复原件只是啰嗦；重复投影是把一个会过期的事实复制了 N 份，而 N 是多少、在哪里，无人知道。
- 「[转述 ≠ 出处](../../playbook/multi-contributor-protocol.md)」两天前刚立，管的是**跨窗口**转述要溯源，是纪律；**仓内**副本没有对应条款，也没有闸。按元原则第七条，没有闸的规则是纸面的。

**幽灵 lane 是同一个病换了介质**：lane 记录 12 个字段里，`worktree`/`branch`/`base`/`base_sha_at_claim`/`status` 全是 git 已有事实的副本，且**没有对账回路**。而 `truth-hierarchy` §五¾.2 早写过「长期状态文件不 self-pin live HEAD」——那条规矩为文档写，**从没应用到本仓自己的工具上**。

最锋利的一例（实测）：某条 lane 记录的 `branch` 是 `docs/v0170-release`，树上实际是 `claude/gracious-shtern-07ae02`；`clean` / `merged` 这些安全判据都在真树上量，唯独 `branch` **只被打印、从不被核**，于是审计报告用测量的口气说出了一份拷贝，还给它配了 `reclaim safe`。

## 修法

1. **把「原件 / 投影」立成第一类区分**，写进真相源治理（[truth-hierarchy §仓内投影](../../playbook/truth-hierarchy.md)）。跨仓面早有三根钉子（pin 版本 / 只映射不复制 / 显式升级），仓内面一根都没有——补上同构的三根。
2. **锚必须点到符号，不是文件**：`<!-- src: cli/src/guard.rs#commit_push_dirs -->`。
3. **配一条对账命令**：`agent-on drift` 只回答「哪些副本和源对不上」，两条介质一起答（台账 4 类 + 文档 2 类），每行带 owner 与非破坏出口，**默认只报不拦**。
4. **只管机器行为断言，不管方法主张**。方法主张不会过期，给它上锚是噪音。豁免面写死：`intake/`、`legacy/`、`CHANGELOG.md`。

## 可复用规则

1. **一份记录，先问它是原件还是投影**。原件随便重复；投影每复制一次，就多一个会无声过期的点。**判定错的概率不由文档质量决定，由投影数量决定。**
2. **指到文件的指针，不能证明任何一句关于行为的话**。文件路径的寿命比它内部的行为长得多——它恰恰在行为变了的时候仍然有效，也就是最需要它报警的时候一声不吭。回指必须点到能被验的最小单位。
3. **只被打印、从不被核的字段，是最危险的字段**。它借着周围真实测量的权威流通。识别器：报告里的每一列，问一句「这是量出来的还是抄来的」；抄来的必须标出来，或者干脆别印。
4. **对账命令要和执行闸分开**。账实不符是别人的账，用它拦本会话的写入，就会逼出「为了让闸变绿而改账」。报告 + owner + 一条非破坏出口，比多一盏红灯有用。
5. **给一个仓立规矩时，先查它有没有在别的介质上已经立过**。本次两条钉子（不 self-pin live HEAD、转述≠出处）都已存在，都只覆盖了一半介质。**一条规矩只应用在 N 个同类介质里的 1 个，比没有这条规矩更容易骗人**——它让人以为这个问题已经管过了。
