# 案例 42:闸不说出口,人就变成闸(归因写歪 → 人肉恒红闸)

> 层级:L2 教训 | 来源:Dartify 实战 2026-08-20(用户实测转述,经本仓复现) | 入册:2026-08-20

## 症状

一条会话要改一条 `[landed]` 轨的登记(重钉 `base`),好让自己被挡住的边界放开。它停下来问用户:

> 「这条我能自己跑——要我直接跑吗?上次我未经你批就动别人 lane 的 owns,把全仓 guard 弄红过一次,所以这次先问。」

用户反问:「**不是你跑的话,应该谁来跑呢?**」

会话这才去翻仓,发现 `kit/worktree-control-plane.md` 早就写死了三档持有判据、lane 与值守的分工、以及「`gc` 是 report-only,只有删除保留给人」。结论很清楚:**没有别人,该它自己跑**。跑完 `changed 0`、`behind 0`、`reclaim` 从 `rescue` 降到 `safe`、全局 `RESULT: PASS`。

答案从头到尾都在仓里。它问的不是偏好,是事实。

## 根因

两层,都不在那条 lane 上:

1. **闸的报错只说「谁挡你」,不说「你怎么过」**。原文案是 `owned path X overlaps still-writing lane <id> boundary Y`,以及 `STATUS-DRIFT: … Re-register with edit --status active, or land the work.` 前者零出口;后者给的两条出口一条是错方向(`--status active` 把边界从「事实那几个文件」放大回 `owns` 全量,更红),另一条(land the work)需要一个不存在的会话。**真正管用的第三条——重钉 base 让登记回到事实——没写在任何报错里**,只散在文档三节里,要读者自己拼。
2. **上一次事故的教训归因写歪了**。它真实的错误是**用错了操作**:删别人的 `owns` 只把「占着」变成「越界」,更糟;重钉 `base` 才是让登记与事实对齐。但它学到的是**「凡涉他人 lane 一律先问」**——一条把唯一正确出口也一起禁掉的规矩。于是下一次被同一个闸拦住,它只剩一条路:问人。

第 2 层是第 1 层的放大器:**报错不给出口时,归因写歪的人不会发现自己写歪了**,因为「问人」在他看来一直是有效的。

## 修法

**执行层**——两条消息补齐出口,而且**成对**补:

- `still-writing` 档:「被它挡住的任何会话可以自己修 + `agent-on worktree edit --id X --base <ref>` + 这是**修登记不是删除**(永远别清它的 owns、别删它的树)」。
- `contract`(活轨)档:「那条轨有人在家——缩自己的 owns 或交单给它,**不许**改它的登记」。

只补前者会被读成「我可以改任何人的 lane」;只补后者就是原来那个病。**成对是必需的**,不是对称美学。

**文档层**——`kit/worktree-control-plane.md` 加一张按**破坏性**分档的权限表(不按所有权),把「重钉 base / 改 status / 补占位登记」明确划给**被挡住的人自己做**,把「删 owns」标成错误操作,把「删目录 / 删分支 / `--force` / 代 commit」留给人。

**追问层**——`playbook/elicitation-protocol.md` 在 2×2 前面加第 0 闸:先分事实问题 / 偏好问题。事实问题不许问用户,去查;查了真没有 = 制度缺口,问的同时带制度补丁提案。

## 可复用规则

1. **每条 FAIL / WARN 必须凑齐三件:谁能清、清的命令、清不掉时为什么**。缺「谁」的诊断行没有主语,读的人只会往上级推;缺「命令」的出口等于没有出口;把「改登记就能清的漂移」和「改登记清不掉的债」写成一个样,红灯就失去意义。
2. **出口要成对补**。给了修复权就要同时划出禁区,否则读者会把出口推广成通行证;只划禁区不给出口,就是恒红闸。
3. **事故复盘过三问**:①出事的是**哪一个具体动作**(不是「哪一类东西」)?②同目标下**正确的动作**是什么?③新规矩会不会把那个正确动作也禁掉——会,就是学歪了,重写。
4. **「每次都先问」不是谨慎,是人肉版的恒红闸**。「为别的东西亮红灯不是谨慎,是噪音;恒红的闸不含任何信号」这句写的是机器闸,对人同样成立:每次都问 = 每次都不含信息,真该拍板的那几件会被淹掉。
5. **判权限看破坏性,不看所有权**。幂等、可回滚、不碰内容的登记修正,谁被它挡住谁就能做;不可逆的删除永远留给人。等一个 `[landed]` 轨的会话回来批准,等的是一个不会来的人。
